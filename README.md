Personal portfolio of **Youssef Saeed**, Data Analytics Tech Lead.

- Power BI dashboard projects with full report pages
- Data science research project (demand forecasting and inventory optimisation) with a live demo

Live site: https://youssefsaeed-portfolio.vercel.app/

## Structure

```
index.html              the whole site (HTML, CSS and JS in one file)
img/                    dashboard screenshots, event photo, logos
Youssef_Saeed_CV.pdf    downloadable CV
```

## Run locally

Open `index.html` in any browser. No build step needed.
